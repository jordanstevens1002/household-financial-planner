# Changelog

All notable user-facing changes are documented here.

## [1.0.0] - 2026-07-29

### Added

- self-hosted FastAPI, PostgreSQL and Appsmith application;
- isolated households, people, properties, ownership, rental and loan records;
- income, expenses, tax profiles and backend household cash flow;
- retirement accounts, contributions and projections;
- observed, planned and projected timeline events;
- saved scenarios, templates, inheritance and comparison;
- country-neutral provider registries with bundled Australian examples;
- maintained ISO country and currency reference data;
- structured logging, environment configuration, migrations and Docker health checks; and
- release documentation, backup guidance and opt-in fictional demo data.
